# MinerU 接入与联网收藏（save_web_file）——使用与验收

2026-09-23 落地。两件事共用一个解析引擎（MinerU）：手动上传 PDF 的解析升级，和小笔「搜到好文件存进库」的新能力。

## 你需要做的一步：申请免费 token

1. 到 https://mineru.net/user-center/api-token 注册/登录（免费，每天 2000 页额度，单文件 200MB）
2. 把 token 配到笔记库 `.env` 文件里一行：`NB_MINERU_TOKEN=你的token`，然后重启应用（关掉 启动.bat 再开）

**不配 token 会怎样**：一切照旧——上传 PDF 走原来的本地解析；小笔的存文件功能只能存网页和 md/txt，存 PDF 时她会提示你去配 token。配了之后自动切换，无需其他操作。

## 功能一：上传 PDF 解析升级

- 上传弹窗照常用，PDF 自动交给 MinerU 云端解析（约 1~2 分钟，公式/表格/扫描件比原来的本地解析好很多）
- 「同时保留原始 PDF」勾选后原件在库里，解析失败时可以用「导入 PDF」入口（本地管线）重试，不会白丢文件
- 没配 token 时走的还是原来的本地解析

## 功能二：小笔联网收藏

对她说「把这个存进库 / 收着」，附上链接即可。她可以用 `web_search` 搜到好资源后主动问你要不要存。

- PDF/Word/PPT/Excel 直链：MinerU 云解析成可批注的 md 文章，插图落 `assets/`
- 网页：转成 md 存档
- md/txt 直链：原样落盘
- 图片不收（不是可检索知识），需手动上传
- 永不覆盖已有文件（重名自动 -2/-3）；目录必须已存在；存完她会把文件路径和来源 URL 都给你

**边界**：`save_web_file` 是小笔唯一能往笔记库写文件的通道（AGENTS.md 已加例外条款），只准新增、永不覆盖；`run_code` 的写权限铁律不变。

## 验收清单（token 配好后）

| 步骤 | 预期 |
|---|---|
| 上传一个 PDF（勾选保留原件） | 约 1~2 分钟后生成 md，结果页显示「? 页 + 原件已保留」 |
| 对小笔说「把 https://example.com 存进知识库」 | 她调 save_web_file，左栏树自动刷新出现新文章 |
| 已配 token 的验收记录 | 补记在本文件下方 |

## 已知限制

- GitHub/AWS 等国外直链在 MinerU 侧可能超时（官方文档明说）——换源或手动下载上传
- 免费档高峰要排队，超过 4 分钟会报超时，稍后重试即可
- 页数显示为「? 页」（MinerU 不回传页数，后续可从结果包里数）
