# 注意力机制：一张速记卡

## 一句话版本

注意力就是**加权平均**：对每个位置算一个权重，权重由「当前查询」和「各位置的键」的相似度决定，
再用权重把「各位置的值」加起来。

## 公式

缩放点积注意力：

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V
$$

为什么要除以 $\sqrt{d_k}$：维度越高，点积的方差越大，softmax 会被推向极端值，
梯度随之变小。除一个与维度相关的常数，是把分布拉回可训练区间的最简做法。

## 最小的实现

```python
import numpy as np

def attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)      # 相似度
    scores -= scores.max(axis=-1, keepdims=True)   # 数值稳定
    w = np.exp(scores) / np.exp(scores).sum(axis=-1, keepdims=True)
    return w @ V                          # 加权平均
```

三行核心：算相似度 → softmax 归一 → 加权求和。

## 几个容易记混的点

- **Q 和 K 不同**：Q 是「我在找什么」，K 是「我能提供什么」。同一个序列同时充当两者时，
  是自注意力（self-attention）。
- **多头不是简单复制**：每个头有自己的投影矩阵，各自关注不同的关系模式，
  最后拼起来再投影一次。
- **注意力的代价**：序列长度 n 的时候，分数矩阵是 $n \times n$。
  这是后来一堆「稀疏注意力 / 线性注意力」工作的起点。
