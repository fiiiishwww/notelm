# 怎么用这个示例库

这个文件夹是一个**可以直接玩的示例笔记库**。你不需要准备任何材料。

## 三种开始方式

1. **看界面**：启动应用后在笔记库选择页把目录指到 `examples/sample-library`，
   立刻能看到目录树、正文渲染、批注面板。这一步不需要 API Key。
2. **试 AI**：在设置里填一个 OpenAI 兼容接口的 Key（任何厂商都行），
   然后在小抄/闪卡入口对某篇笔记点生成，观察覆盖率质量门与去重是怎么工作的。
3. **试复习**：生成闪卡后，「今天」栏会把这些卡按 SM-2 到期时间排成一份行动清单。

## 这个库里有几篇笔记，故意放了不同的东西

| 笔记 | 放进去的东西 |
|---|---|
| `间隔重复-为什么有用.md` | 多级标题、列表、表格 —— 验证目录树与结构化渲染 |
| `注意力机制-速记.md` | 数学公式、代码块 —— 验证 KaTeX 渲染与块级锚点 |
| `本地优先-笔记软件的取舍.md` | 长段落、引用 —— 适合拿来试批注与锚点自愈 |

## 试几个边界

- 用外部编辑器（VS Code、Obsidian）改这个文件夹里的 md，回到应用看批注锚点能不能自动贴回去
- 把一篇笔记的标题改掉，看目录树怎么更新
- 在应用里删除一段文字，看回收站（`.notebook/trash/`）里有没有留底

> 这个示例库是干净的：里面没有任何私人内容，你可以随意改动、删除。
